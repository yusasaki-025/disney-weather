# マイハマびより ユーザーマニュアル

舞浜の天気からショー ・ パレード中止リスクを予測する個人向けツールです。
同行者と URL を共有しながら「行く日」を相談する用途を想定しています。

公開 URL : <https://disney-weather.pages.dev>

---

## 1. 何ができる?

- 今日 ＋ 14日 (15日分) の天気予報を、複数ソースで比較
- 1日ごとに **総合スコア (ベスト / OK / 微妙 / 別日)** を表示
- 風 ・ 雨 ・ 熱 (WBGT) のリスクをショー別に判定 (バッジ表示)
- ショー ・ パレードの開始時刻 (公式取得 ・ 一部実データ)
- 行をタップで詳細パネル展開 (時系列グラフ ・ ショースケジュール ・ 服装サジェスト)
- 過去同条件で何% 中止だったか (cancel-history ベース、Phase 3)

---

## 2. スコアの見方

| 表記 | 意味 | 色 |
|---|---|---|
| **ベスト** | 風 ・ 雨 ・ 暑さすべて OK | 緑 |
| **OK** | 軽微なリスクのみ | 薄緑 |
| **微妙** | 風バ or 雨バの可能性 | 黄 |
| **別日** | 中止リスク高 | 赤 |

スコアの算定は **昼パレード時刻 (TDL 13:00 / 14:30 ・ TDS 11:30 / 14:00) の前後1時間** を最重視 (季節限定の昼パレードが鑑賞価値高いため)。ナイトパレードは通年演目で参考扱い。

---

## 3. バッジの読み方

各カードに3つのバッジが出ます。

### 風バッジ

ショー別の閾値で判定 (過去風キャン記録から実測):

- **通常** : 風キャン基準以下
- **風バ可能性** : 風バ閾値超え (ハーモニーは 6m/s〜、ビリーヴは 5m/s〜)
- **中止リスク高** : 風キャン閾値超え (大半のショーは 12m/s〜、エレクトリカルは 10m/s〜)
- **ほぼ中止** : さらに強風

特に **Reach for the Stars** は花火パートが 8m/s でパイロカット (花火だけ削除)。

### 雨バッジ

- **通常** : 降水確率 30% 未満
- **雨バ可能性** : 30 - 60% かつ降水量 1mm/h 未満
- **雨キャン濃厚** : 60% 以上 or 1mm/h 以上
- **ほぼ中止** : 2mm/h 以上

### 熱バッジ (WBGT)

WBGT (暑さ指数) で判定 :

- **通常** : 25 未満
- **暑さ注意** : 25 - 28 (警戒)
- **熱バ可能性** : 28 - 31 (厳重警戒)
- **熱キャン濃厚** : 31 - 33 (危険)
- **ほぼ中止** : 33 以上

WBGT は環境省実値 (4 - 10月) または簡易計算 (期間外)。ヘッダーで現在のソースが確認できます。

## 4. 操作

### 並び替え ・ 絞り込み

- 並び順 : 日付順 / スコア順
- 曜日 : すべて / 平日のみ / 土日祝のみ
- おすすめ日のみチェック : ベスト or OK の日のみ表示

設定は自動保存されます (ブラウザの localStorage)。

### パーク切替

詳細パネル内に **TDL / TDS タブ** があります。それぞれのショースケジュールが見えます。

### 詳細パネル

カード (またはテーブル行) をタップで開閉 :

- **時間帯スコア** (朝 / 昼 / 夜) 重みは 朝 0.5 ・ 昼 2.0 ・ 夜 0.3
- **ショー ・ パレード** (TDL / TDS タブ)
  - **太字** = 季節限定 ・ 鑑賞価値高 (ハーモニー等)
  - 通常 = 屋内 / エントリー受付対象
  - **グレー** = 通年演目 ・ 参考表示 (エレクトリカル等)
- **持ち物 ・ 服装サジェスト** (気温 / 雨 / UV から自動)
- **雨雲レーダー** (当日 ・ 前日のみ気象庁公式へ直リンク)
- **時系列グラフ** (降水確率 ・ 風速)

### URL 共有

ヘッダーの **「URL コピー」** で共有 (廃止済 ・ ブラウザの共有機能を使用)。スマホはアドレスバーから共有メニュー → LINE / メッセージ / メール。

### ホーム画面に追加 (iPhone Safari)

1. 画面下部の共有ボタン (□↑) をタップ
2. **「ホーム画面に追加」** を選ぶ
3. 「マイハマびより」アイコンがホーム画面に出る

アプリのように起動でき、毎日サッと開けます。

## 5. 注意事項 (disclaimer)

このツールは公開天気予報からの **推定** であり、運営の公式発表ではありません。
当日の正確な運営状況は **東京ディズニーリゾート公式サイト ・ アプリで必ず確認** してください。

- 当日の風キャン / 熱キャン / 雨キャンの最終判断はキャストが行います
- パレード時刻は公式公開後に手動更新するため、直前変更は反映遅延あり
- WBGT 簡易計算は ±1.5℃ 程度の誤差があります

## 7. よくある質問 (FAQ)

### Q. なぜ「別日」表示なのか?

A. 風 ・ 雨 ・ 熱のいずれかで中止リスクが高いとき (バッジが「中止リスク高」「ほぼ中止」等)、総合スコアに下限ガード (§0.16) がかかります。詳細パネルで内訳を確認してください。

### Q. 公式と公演時刻が違う日がある

A. 公式更新を月1で取得しているため、直近の変更は反映遅延 (1-2週間) があることがあります。公式アプリを併用してください。

### Q. WBGT が「簡易計算」「環境省」両方表示される

A. 環境省は 4 - 10月のみデータ提供。期間外は気温 + 湿度からの簡易計算 (±1.5℃ 誤差) で代替します。ヘッダーのソース表示で切り替わります。

### Q. 印刷したい

A. ブラウザの印刷機能で OK (専用の印刷モードは廃止済)。

### Q. PWA 化したい (アプリのように使いたい)

A. iOS Safari なら「ホーム画面に追加」できます (§4 操作参照)。Android Chrome も同様 (右上メニュー → 「ホーム画面に追加」)。

### Q. 同行者と共有したい

A. URL をそのまま LINE / メッセージで送ってください。同行者のスコアや投票機能はありません (シンプルさ優先)。

### Q. 通知が欲しい

A. Phase 3 で LINE / メール通知を検討中。今は手動でブックマークから確認してください。

### Q. バグ ・ 要望

A. GitHub Issues (<https://github.com/yusasaki-025/disney-weather/issues>) or 直接連絡。
