## 4. ルール (これまでの反省踏まえ ・ 必ず守る)

- **1 PR = 1 Issue** (混ぜない)
- Edit 前に対象ファイルを必ず `Read`
- commit 前に `npm test` + `npm run build` の exit code を確認
- commit 直後に `git show HEAD:file | grep` で着地確認 (消えてたら再投入)
- 並行プロセス (linter / 別 Cowork セッション) に注意 ・ 編集巻き戻しに警戒
- push 後は `https://disney-weather.pages.dev` で実機確認 → 違和感あれば Issue にコメント
- 仕様書 (docs/CHANGES.md) の表記揺れに注意 ・ 「降水確率」を「降水量」にするような誤実装をしない
- 報告書には「実装した」だけでなく「ブラウザ実測でも仕様文言と一致」を確認 (§0.41.7 のような誤実装の早期発見)
