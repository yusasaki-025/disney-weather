## 【修正1 : ザ・ダイヤモンド・バラエティマスター 屋内判定漏れ】

ユーザー報告 : 「ザ・ダイヤモンド・バラエティマスター は屋内ショーなのに、現状 突風 12.6m/s ･ 基準 風バ 8m/s 〜｜中止 12m/s 〜 (一般基準) という風キャン基準が表示されるのはおかしい」。

原因 : `src/data/show-thresholds.js` の `WEATHERLESS_SHOWS` 配列 (屋内 ･ 天候影響なしとして風バッジ ･ 過去中止率を出さない判定) に「ザ・ダイヤモンド・バラエティマスター」が未登録でした。姉妹の屋内レストランショーである「ミッキーのレインボー・ルアウ」は既に登録済みでしたが、この演目だけ漏れていたため `isWeatherless()` が `false` を返し、`thresholdForShow()` が `DEFAULT_THRESHOLD = { windBa: 8, windCancel: 12 }` (一般基準) にフォールバックし、`src/ui/table.js` の `showRiskLineHtml()` が屋外ショーと同じ風バッジ ･ 基準表示を出していました。

修正 (適用済み・確認のみでOK) : `src/data/show-thresholds.js` の `WEATHERLESS_SHOWS` 配列に以下を追加しました。

```js
/ダイヤモンド[・･]バラエティマスター/, // §0.84 : 屋内レストランショー。WEATHERLESS 未登録のため一般基準の風バッジが誤表示されていた不具合の修正。
```

これにより `isWeatherless('ザ・ダイヤモンド・バラエティマスター')` が `true` を返し、姉妹ショーと同様「屋内・天候影響なし」表示に切り替わり、風バッジ ･ 風閾値 ･ 過去中止率が非表示になります (熱 WBGT バッジのみ継続表示)。

## 【修正2 : 「過去中止」バッジのラベルが何の基準か分からない】

ユーザー指摘 : 「［過去中止 13% (2/15件)］これは何に対していってるのか分からない。風？雨？熱？」。

原因 : `getCancelProbability()` は突風 (predWind) 基準の過去中止率しか計算していない (title 属性には「過去同条件 (突風 ◯m/s ±2m/s)」と明記されているが、バッジ本体の文言には風であることが書かれていなかった) ため、雨 ･ 熱の中止率も含むように読めてしまう表示でした。

修正 (適用済み・確認のみでOK) : `src/ui/table.js` のバッジ文言を `［過去中止 ...]` → `［過去中止(風) ...]` に変更しました (該当箇所 1 か所のみ、`showRiskLineHtml()` 内の `cancelHtml` 組み立て部分)。
